> 一条一文件。文件名 = 典故词（如 `命令-撤销.md`）。字段照填，禁止删改字段名。
> 去上下文化：**禁止**出现本仓窗号、场景名、文件路径、内部编号。

```yaml
status: pending          # pending | committed | rejected
date: YYYY-MM-DD         # 条目创建日期

symptom: "触发症状：何时该想起这条结构"
pack: "压缩包：适用 / 结构 / 你本仓的验证实例（去上下文化后写，如『一套交互生命周期 + Execute 差异』）"

forbid: "禁用边界：什么情况不要套"

```

## 为什么值得上传
