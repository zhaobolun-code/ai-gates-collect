# 错题：疑问句只答不改文件

> 一条一文件。文件名 = 坑名（如 `疑问句只答不改文件.md`）。字段照填，禁止删改字段名。
> 去上下文化：**禁止**出现本仓窗号、场景名、文件路径、内部编号。

```yaml
status: committed
date: 2026-08-16
name: "疑问句只答不改文件（问号句先答该不该；等确定改法或「准」再改文件）"
category: "Skill流程"
```

## 错因

把「是不是应该改成…？」当成开工口令，疑问未拍板就改文件。

## 改正

问号句先答该不该与为什么；等用户给出确定改法或「准」再改文件。禁止把确认疑问当开工。

## 复发信号

用户带问号在问该不该改，Agent 已经开始改文件或写方案落盘。
