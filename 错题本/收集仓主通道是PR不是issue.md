# 错题：收集仓主通道是PR不是issue

> 一条一文件。文件名 = 坑名。字段照填，禁止删改字段名。
> 去上下文化：**禁止**出现本仓窗号、场景名、文件路径、内部编号。

```yaml
status: committed

name: "收集仓主通道是PR不是issue（开工「准」不等于「上传」）"
category: "Skill流程"
```

## 错因

容易把技能包真源仓的 issue 当收集出口，或把开工的「准」当成开 PR。

## 改正

收集仓上传走 pull request；issue 仅可贴草稿讨论，不是主通道。开工「准」只定版和改码，不开 PR、不建 issue。独立口令「上传」且本机探测成功才允许开 PR。未探测成功禁止自称已通。禁止为此新建平行队列或新岗位。

## 复发信号

手续或方案把「准」写成 `gh pr create` / `gh issue create`，或把技能包真源仓 issue 写成收集仓主出口，或未探测成功仍写「gh 已接线/已通/已下发」。
